# Table-Tennis-Serve-Analysis

For the past 2 years I have been addicted to Table Tennis. I have played 3-6 times a week for a minimum of an hour to a max of about 6 hours. About two months ago I started playing 4 times a week for about 3 hours a session. I even got into competitive play and have reached an elo of 1910. My plan for this Project is as follows. My serve is the strongest part of my game so I aim to perfect that aspect of my game first using this serve analysis tool.

Roadmap
1) Gather the data from my last 100 matches, gather oponent stats, and game scores.
2) Clean Data
3) Create 3 models to figure out optimal serves.
4) Use lasso to see if certain variables lead to a better outcome
